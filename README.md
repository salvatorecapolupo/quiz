# Prototipo App

Questa è la nuova struttura organizzata del progetto.

## Struttura delle cartelle:
- `src/`: Contiene il codice sorgente dell'app (HTML, CSS, JS).
- `config/`: Contiene i file di configurazione come i manifest.
- `tools/`: Contiene script di utilità come `build_manifest.py`.
- `examples/`: Contiene file JSON di esempio per testare l'app.

## Esecuzione dello script Python
Lo script `build_manifest.py` si trova nella cartella `tools/`. 
Best practice: eseguilo dalla root del progetto con il comando:
`python tools/build_manifest.py`
